# Health & Lifestyle SQL Analysis

## 👤 Author
**Tejas Phalke**

## 📄 Project Overview
This project involves analyzing a **Health & Lifestyle dataset** using SQL to extract meaningful insights about individuals' habits and health conditions. The dataset includes features such as physical activity, dietary intake, sleep duration, BMI, smoking and alcohol habits, and more.

## 📁 Dataset Description
The dataset contains 1000 records with the following fields:
- `ID`: Unique identifier
- `Age`, `Gender`
- `Height_cm`, `Weight_kg`, `BMI`
- `Daily_Steps`, `Calories_Intake`
- `Hours_of_Sleep`, `Heart_Rate`, `Blood_Pressure`
- `Exercise_Hours_per_Week`
- `Smoker`, `Alcohol_Consumption_per_Week`
- `Diabetic`, `Heart_Disease`

## 🛠️ SQL Tasks Performed
1. **Table Creation** – Define schema for structured analysis.
2. **Data Preview** – Initial data exploration.
3. **Group Analysis** – Average steps by gender.
4. **Health Insights** – BMI vs. Heart Disease correlation.
5. **Behavioral Trends** – Sleep comparison between smokers & non-smokers.
6. **Heart Impact** – Heart rate influenced by alcohol consumption.

## 📌 Final Insights
- **Gender differences in physical activity.**
- **Higher BMI linked to heart disease.**
- **Smokers get less sleep on average.**
- **Alcohol intake may raise heart rate.**

## ✅ Conclusion
Structured data and SQL queries reveal clear lifestyle patterns that impact health. This analysis promotes data-driven awareness for better health choices.
